# MB Extreme — Downloads

Repositório **público** só para distribuir o instalador do **MB Extreme** e a configuração do canal (redes, ofertas e suporte).

O **código-fonte** fica em um repositório **privado** separado (`mbinfoarte/MB-Extreme`). Aqui ficam apenas:

- As **versões publicadas** (Releases) com o instalador do programa.
- O arquivo `config/canal.json`, que o programa lê para mostrar links, cupons e informações de suporte sempre atualizados.

## Baixar o MB Extreme

➡️ **[Baixar a versão mais recente](https://github.com/mbinfoarte/MB-Extreme-Download/releases/latest)**

Na página de Releases, baixe o arquivo do instalador (`.exe`) do item marcado como **Latest**.

## Sobre o programa

**MB Extreme** é um otimizador e central de ferramentas para Windows, feito pela **MB InfoArt** — _Tecnologia sem complicação_.

- Otimização e limpeza do Windows (ajustes seguros)
- Informações e sensores do PC em tempo real
- Drivers em falta baixados direto pelo Windows Update
- Ferramentas de rede, DNS e teste de velocidade
- Papel de parede, widget flutuante e muito mais
